# Festival Beat Live Frontend

React/Vite で分離したフロントエンドです。

## 開発起動

```powershell
npm install
npm run dev -- --port 5173
```

ブラウザで `http://localhost:5173` を開きます。

## 実装範囲

- ソーシャルゲーム風ロビー画面
- ロビー上の実ボタンによる画面遷移
- 音源アップロード
- Web Audio API による簡易オンセット解析
- 難易度別譜面生成
- 音源同期リズムゲーム
- 記録画面
- 判定オフセット設定
- 3キャラクター選択
- キャラクター別ロビー/ゲーム背景
- ロビー背景画像アップロード
- ストーリーモード
- メモリアル画面

Python/Streamlit 版は既存のまま残しています。
